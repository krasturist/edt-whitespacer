EDT Whitespace Trimmer

Плагин для удаления пробелов и табуляций в конце строк при сохранении файлов в 1C:EDT.

Установка

  1. Откройте «Справка → Установить новое ПО…».
  2. Нажмите «Добавить…».
  3. Укажите адрес сайта обновлений:

https://krasturist.github.io/edt-whitespacer/

Выберите EDT Whitespace Trimmer, завершите установку и перезапустите EDT.

Настройка

Откройте «Окно → Параметры → EDT Whitespace Trimmer» и задайте подстроку для фильтрации путей файлов.
