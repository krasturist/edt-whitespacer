EDT Whitespace Trimmer

Плагин для 1C:EDT, который удаляет пробелы и табуляции в конце строк при сохранении выбранных файлов.

Область обработки задаётся подстрокой в полном пути файла. Например, можно указать префикс собственных объектов demo_ и не применять очистку к остальным модулям.

Установка

  1. Откройте в EDT «Справка → Установить новое ПО…».
  2. Нажмите «Добавить…» и укажите адрес сайта обновлений:
https://krasturist.github.io/edt-whitespacer/
  1. Выберите «EDT Tools → EDT Whitespace Trimmer».
  2. Завершите установку и перезапустите EDT.

Если список компонентов не загрузился, откройте «Окно → Параметры → Установка/обновление → Доступные сайты ПО», выберите сайт и нажмите «Перезагрузить / Reload».

Настройка

Откройте «Окно → Параметры → EDT Whitespace Trimmer». В поле «Подстрока в пути файла» укажите признак, по которому нужно выбирать файлы, например demo_.

  • Проверяется полный путь файла, а не только его имя.
  • Регистр учитывается.
  • Пустое поле или строка только из пробелов отключает очистку.
  • Изменение фильтра применяется при следующем сохранении.
